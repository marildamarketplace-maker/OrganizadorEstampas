# Instruções para agentes de IA

## Finalização de alterações de código

Sempre que alterar código neste repositório, execute `bash build_macos.sh` na raiz do repositório antes de finalizar a tarefa.

Se o build falhar, investigue e corrija os erros relacionados à alteração e execute o comando novamente. Informe no resultado final se o build passou ou, se houver impedimento, descreva o erro e a pendência. Não declare o build como concluído sem verificar o resultado.
